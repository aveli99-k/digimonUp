# digimonUp 매크로

앱플레이어에서 돌아가는 디지몬 게임의 반복 작업을 자동화합니다.
실행하면 GUI 가 뜨고, 거기서 기능을 골라 **시작**을 누릅니다.

| 번호 | 기능 | 하는 일 |
|---|---|---|
| 1 | **네트워크** | 매칭 버튼을 누르고, 포기 버튼이 뜨면 5초 뒤 눌러 반복 |
| 2 | **탐사** | 5x5 게임판을 인식해 장애물을 피해 오른쪽으로 계속 전진 |
| 3 | **던전** | 도전·토벌하기 버튼과 실패창·보상창을 함께 찾아, 보이는 쪽을 눌러 계속 반복 |

탐사는 주황칩을 1순위로 먹으러 가고, **가는 길에 놓인 걸음수·부수기·돌진
아이템은 지나가며 주워 갑니다**(아이템 때문에 돌아가지는 않습니다).

던전은 한 판이 **이기면 보상창, 지면 실패창**으로 끝납니다. 어느 쪽이 뜰지 미리
알 수 없으니 넷을 한꺼번에 찾아 두고 보이는 것을 누릅니다. 팝업은 **왼쪽 위 구석**을
눌러 닫습니다 — 보상창 아래의 *포기* 버튼을 누르면 그 판 보상을 못 받기 때문입니다.

판을 시작하는 버튼은 **`도전` 과 `토벌하기` 둘 다** 봅니다. 누른 뒤에 벌어지는 일이
같아서 같은 대우를 받고, 둘이 한 화면에 보이면 더 확실하게 잡힌 쪽을 누릅니다.
`토벌하기` 는 **없어도 됩니다** — 그 버튼이 안 나오는 던전이면 예전처럼 도전만 봅니다.

**한 번 누르고 몇 초 기다립니다.** 화면이 그대로면 그때 한 번 더 누릅니다.
연달아 누르면 팝업이 닫히는 순간의 클릭이 그 아래 화면으로 새어 나갑니다.

---

## 받아서 바로 쓰기 (파이썬 없이)

**[⬇ digimonUp.exe 다운로드](https://github.com/aveli99-k/digimonUp/releases/latest)**

**파일 하나면 됩니다.** 설정과 인식용 이미지가 EXE 안에 들어 있어서, 압축을 풀거나
다른 파일을 함께 둘 필요가 없습니다.

1. `digimonUp.exe` 를 원하는 폴더에 둡니다
2. 오른쪽 클릭 → **바로가기 만들기** → 만들어진 바로가기를 바탕화면으로 옮깁니다
   (Windows 11 은 오른쪽 클릭 → *추가 옵션 표시* 안에 있습니다)
3. 앱플레이어에서 게임의 **탐사 화면**을 띄웁니다
4. 바로가기를 더블클릭 → 기능을 고르고 **시작**

> **"Windows 의 PC 보호"** 창이 뜨면 개발자 서명이 없어서 그렇습니다.
> **추가 정보 → 실행** 을 누르면 됩니다.

설정을 바꾸거나 템플릿을 자기 화면에서 다시 찍고 싶다면, EXE **옆에**
`config.json` 이나 `templates\` 폴더를 두면 EXE 안의 기본값 대신 그쪽을 씁니다.
다시 빌드할 필요는 없습니다.

---

## 필요한 것

- **Windows** (창 캡처와 클릭에 Windows API 를 씁니다)
- **Python 3.10 이상** — 위 EXE 를 받았다면 필요 없습니다
- **앱플레이어** — MuMuPlayer, LDPlayer, NoxPlayer, BlueStacks, MEmu 등

목록에 없는 앱플레이어도 됩니다. 창 이름이 아니라 **화면에 5x5 게임판이 보이는지**로
창을 고르기 때문입니다.

## 시작하기

```bash
pip install -r requirements.txt
```

**1. 앱플레이어에서 게임의 탐사 화면을 띄웁니다.**

**2. 창이 잡히는지 확인합니다.**

```bash
python tools\detect_windows.py
```

게임 창의 격자 점수가 `0.45` 이상이면 준비 끝입니다.
안 잡히면 이 도구가 원인과 다음 조치를 알려줍니다.

**3. 실행합니다.**

```bash
python launcher.py
```

멈추려면 **`F12`** 를 누르거나 GUI 의 **정지** 버튼을 누릅니다.
둘 다 대기 중이던 클릭까지 즉시 취소합니다.

> 버전은 창 제목과 상태 줄 오른쪽에 보입니다. 로그 첫 줄에도 남으므로,
> 문제를 알려 줄 때 로그를 그대로 보내 주시면 됩니다.
> 콘솔에서는 `python launcher.py --version` 으로도 확인할 수 있습니다.

> `F12` 는 **어느 창에서 눌러도** 먹습니다. 매크로가 마우스를 움직이는 중에는
> 정지 버튼을 겨냥하기 어려우므로 키가 편합니다. 키는 `config.json` 의
> `stop_key` 로 바꿀 수 있고, 비워 두면 키로는 멈추지 않습니다.

> 매크로를 두 개 띄우면 같은 게임 창에 서로 클릭을 날려 둘 다 망가지므로,
> 중복 실행은 자동으로 막혀 있습니다(기존 창이 앞으로 나옵니다).

### EXE 로 직접 빌드하기

```bash
scripts\build_exe.bat
```

`dist\digimonUp.exe` 하나가 생깁니다. `config.json` 과 `templates\` 가 안에 들어가므로
그 파일만 옮기면 다른 PC 에서도 그대로 돌아갑니다.

## 템플릿에 대하여

`templates\` 의 이미지는 이 저장소 주인의 화면에서 잘라낸 것이라, 해상도나 게임
스킨이 다르면 잘 안 맞을 수 있습니다. **템플릿이 하나도 없어도 색 기반 인식으로
동작하도록** 만들어 두었으니 일단 그대로 돌려보고, 인식이 시원찮을 때만 다시 찍으세요.

```bash
python tools\capture_explore.py
```

**던전(3번)은 예외로 템플릿이 반드시 있어야 합니다.** '도전' 버튼, '실패...'
글자, '보상' 글자는 색만으로는 옆의 '초기화' 버튼과 갈라낼 근거가 없습니다.
저장소에 든 것으로 안 잡히면 아래로 다시 찍으세요.

```bash
python tools\capture_dungeon.py
```

> '실패...' 는 **그 줄만** 잘라주세요. 윗줄은 `던전` / `스테이지` 처럼 그때그때
> 바뀌는 이름이라, 같이 넣으면 다른 던전에서 못 알아봅니다.
> '보상' 은 뒤에서 반짝이는 이펙트가 돌아서 **서로 다른 순간에 두세 장** 찍어두면
> 안정됩니다.

`토벌하기` 는 메뉴 **4번**입니다. 이것만은 **안 찍어도 됩니다** — 그 버튼이 안 나오는
던전을 도신다면 건너뛰고 나머지는 그대로 돕니다. 저장소에 든 것은 '로스트 섹터 타워'
팝업에서 딴 것이라(703x1250), 다른 화면 크기나 다른 토벌 던전에서 안 잡히면 다시
찍으세요.

## 잘 안 될 때

먼저 `python tools\detect_windows.py` 를 돌려보세요. 매크로가 실제로 보는 화면을
`debug\windows\` 에 저장해줍니다.

| 증상 | 조치 |
|---|---|
| 후보 창이 0개 | 앱플레이어가 최소화돼 있으면 캡처가 안 됩니다. 창을 띄워두세요 |
| 캡처가 검은 화면 | 앱플레이어의 그래픽 렌더링을 DirectX ↔ OpenGL 로 바꿔보세요 |
| 화면은 보이는데 격자 0 | 탐사 화면이 맞는지 확인하고 `board_min` 을 `0.35` 로 낮춰보세요 |
| 엉뚱한 창을 고름 | `window_title_hint` 에 창 제목 일부를 적으세요 |
| 엉뚱한 칸을 클릭 | `debug\last_overlay.png` 에서 격자선이 게임판과 맞는지 보세요 |
| 판단이 이상해 보임 | 아래 **기록해서 확인하기** 를 쓰세요 |
| 클릭이 안 먹힘 | 게임이 관리자 권한이면 매크로도 관리자 권한으로 실행하세요 |

### 기록해서 확인하기

"칩을 무시했다", "길이 있는데 장애물을 부쉈다" 같은 것은 **그 순간의 화면이
있어야** 원인을 알 수 있습니다. 실제로 그렇게 지목된 사례를 뒤져 보면 매크로가
맞았던 적도(진짜 칩이었다, 정말 갇혀 있었다) 진짜 버그였던 적도 있었습니다.

```bash
python tools\record.py 300
```

5분 동안 돌면서 사이클마다 **인식 결과와 계산한 경로를 그린 그림**을
`debug\record\` 에 남깁니다. 이상한 동작을 보면 그때가 몇 초쯤이었는지만
기억해 두었다가 그 무렵 파일을 열어 보면 됩니다. 파일 이름에 시각과 판단이
들어 있고, `log.txt` 에 모든 판단이 시각과 함께 적힙니다.

## 아이템 개수 읽기

왼쪽 아래의 **걸음수 / 부수기 / 돌진** 개수를 읽어서, 남은 게 0개면 아예 시도하지
않습니다. 걸음수를 다 쓰면 매크로가 스스로 멈춥니다.

숫자를 읽으려면 0~9 모양이 필요한데, 저장소에는 만든 사람 화면에서 딴 것이 들어
있습니다. 개수가 `?` 로 나오면 아래를 실행해 채우면 됩니다.

```bash
python tools\capture_counters.py
```

화면에 보이는 세 숫자를 입력하면 그 글자들을 잘라 저장합니다. **다 모으지 않아도
됩니다** — 못 읽는 줄은 `?` 로 두고, 그 항목만 예전처럼 '해 보고 판단'합니다.

## 자주 바꾸는 설정 (`config.json`)

| 키 | 기본값 | 설명 |
|---|---|---|
| `explore.window_title_hint` | `""` | 앱플레이어를 여러 개 띄웠을 때 쓸 창의 제목 일부 |
| `explore.board_min` | `0.45` | 5x5 격자 검출 최소 신뢰도. 못 찾으면 낮추세요 |
| `explore.move_timeout_sec` | `2.2` | 한 칸 이동 확인 최대 대기 |
| `explore.watch_counters` | `true` | 왼쪽 아래 아이템 개수를 읽어 헛클릭을 막습니다 |
| `explore.stop_when_out_of_steps` | `true` | 걸음수를 다 쓰면 매크로를 멈춥니다 |
| `explore.save_debug` | `true` | 디버그 이미지 저장 (끄면 조금 빨라집니다) |
| `confidence` | `0.85` | 1번 기능의 템플릿 일치 기준 |
| `giveup_delay_sec` | `5.0` | 1번 기능에서 포기 버튼 등장 후 클릭까지 대기 |
| `dungeon.challenge_min` | `0.8` | '도전' 버튼 최소 유사도. 못 찾으면 낮추세요 |
| `dungeon.subjugate_min` | `0.8` | '토벌하기' 버튼 최소 유사도 |
| `dungeon.subjugate_band` | `[0.65, 0.95]` | '토벌하기' 를 찾을 세로 범위(화면 높이 대비). 도전 버튼과 같은 자리입니다 |
| `dungeon.fail_min` / `reward_min` | `0.7` | '실패...' / '보상' 글자 최소 유사도 |
| `dungeon.popup_close_point` | `[0.085, 0.048]` | 팝업을 닫으려고 누를 바깥 여백 위치(비율) |
| `stop_key` | `"F12"` | 중지 키. 어느 창에서 눌러도 먹습니다 |

나머지 항목은 [내부 동작 노트](docs/INTERNALS.md#설정-configjson)에 정리돼 있습니다.

## 구성

| | |
|---|---|
| `launcher.py` | 진입점. 인자 없으면 GUI, `1`/`2`/`3` 을 주면 콘솔 실행 |
| `digimonup/base/` | 경로·설정·이미지 입출력 (게임과 무관한 바닥층) |
| `digimonup/vision/` | 화면에서 무엇이 보이는지 — 격자, 셀, 개수, 오버레이 |
| `digimonup/logic/` | 무엇을 할지 — 경로 계산, 칩 추적 (화면도 창도 모릅니다) |
| `digimonup/win/` | 윈도우에 붙는 부분 — 창 찾기, 캡처, 클릭, 중복 실행 막기 |
| `digimonup/app/` | 기능 본체와 화면 — 탐사, 네트워크, 던전, GUI |
| `tools/` | 창 진단, 템플릿 캡처, 인식 점검, 아이콘 생성 |
| `scripts/` | 실행·빌드·바로가기 스크립트 |
| `assets/` | 앱 아이콘 (`tools/make_icon.py` 로 만듭니다) |
| `tests/` | 자동 테스트 (253개) |

층은 아래에서 위로만 의존합니다. `logic` 은 화면도 창도 모르기 때문에
에뮬레이터 없이 그대로 테스트할 수 있습니다.

```bash
python -m pytest tests -q
```

에뮬레이터 없이도 돌아갑니다. `tests/synth.py` 가 실측 HSV 값으로 게임 화면을
합성하고, `tests/fixtures/` 의 실제 캡처로 현실성을 함께 검증합니다.

정적 검사도 함께 돌립니다. 자동 테스트가 닿지 않는 `tools/` 의 이름 사고를
잡아 주는 자리입니다(설정은 `ruff.toml`).

```bash
python -m ruff check .
```
